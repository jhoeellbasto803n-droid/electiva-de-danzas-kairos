# KAIROS · todas las versiones

Este repositorio guarda las versiones del proyecto KAIROS, cada una en su rama.

| Rama | Contenido |
| --- | --- |
| `main` | Versión Python base (`electiva-de-danzas-python`) |
| `agente-local-sin-n8n` | Copia activa con asistente local y importación de materias |
| `n8n-espera` | Copia en espera con integración n8n |
| `nodejs-2.2.0`, `nodejs-2.3.0` | Versiones Node.js |
| `python-2.2.0`, `python-2.3.0` | Versiones Python 2.2.0 y 2.3.0 |
| `versiones-2.1.0`, `con-cuentas`, `mejorado`, `inicial` | Versiones históricas |
| `tipografia-node`, `tipografia-python` | Versiones con tipografía |
| `python-1.0.0`, `agente-local-zip` | Versiones archivadas |

La carpeta `versiones_zip/` contiene todos los ZIP originales, saneados: se
excluyeron `.env`, `.venv`, cachés y logs. Los `.env.example` se conservan.

Nota: la documentación Word y el Excel de prueba están en `docs/` de la rama
`agente-local-sin-n8n`.
